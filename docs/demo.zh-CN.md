# 演示流程与验证

[English](demo.md) | [简体中文](demo.zh-CN.md)

![PhotosAssistantNAS 工作流程](media/overview.svg)

上图是流程示意，不是 Photos 截图或实机录像。下面列出的是已记录的 NAS 测试结果，不是伪装成实时运行的动画。

本流程重点演示“不安装桌面 Image Assistant 的网页上传”和“File Station/SMB 导入 Photos 已索引目录”。如果手机备份已经能够正常预览和播放，通常不需要额外服务。手机端 Image Assistant 开关可在浏览时为这些导入项目生成 JPEG 预览，但不生成压缩兼容视频。详见[群晖对桌面端与移动端的说明](https://kb.synology.com/en-eu/DSM/tutorial/Unable_to_view_HEIC_photos_HEVC_videos_on_Synology_Photos)。

## 已经检查了什么

| 检查 | 实测结果 |
| --- | --- |
| 最初 SSH 实现的 Photos 接入 | 合成 HEIC、HEVC 的缩略图状态变为 ready；合成视频的 high 兼容副本变为 ready |
| 0.5.1 图片处理 | 三张现有 HEIC 生成九个缩略图，解码后的像素与 0.5.0 相同 |
| 10 位、旋转、透明通道 | 合成样本的输出像素与旧方案相同 |
| 48 MP 图片 | 8000×6000 合成 HEIC 成功生成三种尺寸 |
| 图片临时写入 | 目录事件监测只观察到最终 JPEG 的创建，没有原图副本、编码中间图或像素缓存文件 |
| 失败清理 | 损坏 HEIC 被拒绝，任务目录自动删除 |

详见[完整验证及未验证范围](compatibility.zh-CN.md)，其中原生手机 App 播放尚未充分验证。不承诺输出与官方 Image Assistant 完全相同。最初 SSH 接入测试和 0.5.1 解码测试是分别完成的检查，不表示每个客户端、每种素材都完成了端到端验收。

## 在自己的 NAS 上做小规模测试

先准备独立备份和非重要测试素材。目前仅支持指定版本的 x64 DSM / Photos **1.9.1-10928**，完整实测 DSM 版本见兼容性文档。项目会运行 root 服务，并使用未公开的 Photos 接口。先阅读[免责声明](../DISCLAIMER.zh-CN.md)和[安装说明](../README.zh-CN.md#ssh-在线一键安装)。

1. 关闭所有参与测试客户端上的 Image Assistant。选择一张 HEIC 和一段短 HEVC，最好此前没有在这个相册库中处理过。仅给旧项目改名，仍可能触发重复检测或复用已有资源。
2. 在个人空间的小型测试目录中，不经客户端处理上传素材，或复制到自己已被 Photos 索引的目录。不要删除已有项目的资源来强制制造测试条件。
3. 在 NAS 上检查服务、查看日志：

   ```sh
   sudo systemctl is-active photos-assistant-nas.service
   sudo tail -f /volume1/@PhotosAssistantNAS/state/worker.log
   ```

   如果安装卷不是 `/volume1`，请替换为实际位置。按 `Ctrl+C` 只退出日志查看，不停止服务。

4. 服务每 60 秒扫描一次。Photos 完成索引并标记为受支持的缺失/损坏状态后，服务才会处理；索引与视频编码可能需要更久。观察同一个项目 ID 先出现 `source=readonly-fd`，再出现 `processed`；后者在 Photos 报告提交资源已就绪后才记录。已有可用资源会跳过，没有日志不能单独证明处理失败。失败项目默认一小时后重试。
5. 刷新 Photos，检查图片缩略图和打开后的预览，确认方向、颜色；检查视频封面及兼容播放。原本兼容的视频可能只补缩略图，不生成新副本。手机 App 的表现应作为待反馈的实测结果，而不是预先保证。
6. 若要核对原件字节，在处理前后对同一测试原件运行以下命令，替换示例路径：

   ```sh
   sha256sum "/path/to/test.heic"
   ```

   校验值一致仅检查字节，不代表检查了所有文件系统属性。测试时保留原件位置；完成后可通过 Photos 删除不需要的测试素材，不要删除整个 `@eaDir`。

`readonly-fd` 日志说明选择了句柄输入，**不能单独证明没有临时写入**。上面的无副本/缓存观察使用了操作系统目录事件监测。最终缩略图、发布暂存、日志与兼容副本仍然需要写盘，操作系统也可能将内存换出到磁盘。

## 适合分享的简短录像

实际录屏时请使用合成或非私人素材。展示客户端 Assistant 已关闭、新测试素材上传、对应的脱敏日志，以及 Photos 中的结果。保留同一个项目 ID，让观众能对应处理与接收状态。可剪掉等待，但应标注时间跳转，不把剪辑后的录像称为实时处理速度。隐藏账号、主机、私人媒体、路径、Cookie 和无关通知。

仓库目前提供流程图和可复现步骤，**没有提供 Photos 实机录屏**。分享录像时请注明准确版本并链接[兼容性说明](compatibility.zh-CN.md)。可直接使用的介绍文字见[社区介绍帖草稿](community-post.zh-CN.md)。
